# QQP Semantic Textual Similarity

A plain HTML, CSS, and JavaScript dashboard plus a small Python API for detecting
duplicate question pairs in the Quora Question Pairs dataset.

The project compares three approaches while keeping the core modeling pipeline
easy to inspect:

- TF-IDF cosine similarity baseline
- TF-IDF difference/product features with Logistic Regression
- Sentence-BERT MiniLM embeddings with cosine similarity

## Features

- Focused duplicate-question prediction from a browser UI
- Chat-style sidebar with new checks and saved history
- History view that shows each input pair and model output
- Cached model loading for repeated predictions
- Command-line prediction interface

## Project Structure

```text
.
├── app.py              # Static dashboard server and JSON API
├── public/             # Plain HTML, CSS, and JavaScript dashboard
├── pipeline.py         # Core preprocessing, training, and prediction pipeline
├── cli.py              # Terminal prediction interface
├── evaluate.py         # Evaluation script for all models
├── download_data.py    # QQP sample download script
├── data/questions.csv  # Local QQP sample
├── outputs/            # Metrics and plots generated by evaluate.py
└── requirements.txt
```

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Run The App

```bash
python3 app.py
```

Then open the local URL printed by the server. By default it is:

```text
http://127.0.0.1:8501
```

## Command-Line Prediction

```bash
python3 cli.py "How can I learn Python?" "What is the best way to learn Python?"
```

The CLI defaults to `model2`, the offline-capable TF-IDF + Logistic Regression
model. To use Sentence-BERT:

```bash
python3 cli.py --model model3 "How can I learn Python?" "What is the best way to learn Python?"
```

## Regenerate Evaluation Artifacts

```bash
python3 evaluate.py
```

This writes:

- `outputs/metrics.csv`
- `outputs/roc_curves.png`
- `outputs/cm_model1.png`
- `outputs/cm_model2.png`
- `outputs/cm_model3.png`

## Data

The included dataset is a stratified sample of Quora Question Pairs with:

- `question1`
- `question2`
- `is_duplicate`

To rebuild the sample from Hugging Face GLUE QQP:

```bash
python3 download_data.py
```

## Notes

The browser dashboard and CLI default to the Logistic Regression model so the
project works without external downloads. The first Sentence-BERT prediction may
take longer because the MiniLM model has to load into memory. If the model is
not already cached locally, the `sentence-transformers` library may need network
access to download it.
